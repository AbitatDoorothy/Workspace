# Public Hosted Mobile Control Acceptance

- [ ] Fresh Mac has no Abitat CLI or host daemon config.
- [ ] `brew tap Abitat/abitat` succeeds.
- [ ] `brew install abitat` installs an `abitat` executable.
- [ ] `npm install -g @abitat_reece/cli` installs an `abitat` executable and the packaged host daemon dependency.
- [ ] `abitat doctor` reports that login is missing.
- [ ] `abitat iphone` opens hosted browser login.
- [ ] New user registers or logs in at `https://workspace.abitat.io`.
- [ ] Mac appears online in the hosted dashboard.
- [ ] iPhone app opens with API URL `https://workspace.abitat.io`.
- [ ] Pairing code from the hosted dashboard pairs the phone.
- [ ] Phone on cellular starts a Codex task.
- [ ] Mac daemon receives the hosted job.
- [ ] Phone receives streamed messages and final status while off Wi-Fi.
- [ ] Phone receives a completion notification.
- [ ] A second account cannot see or pair to the first account’s Mac host.
